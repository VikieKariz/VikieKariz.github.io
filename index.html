frequently asked questions

Everything you need to know before getting started.

Is the demo on this page the real product?

No — the demo runs in a separate page inside an iframe, and it's a mock design inspired by ERPNext's UI. It has no backend, no database and no real transactions; sample data resets when you refresh. The real product is a full Shop Management System with accounts, live data, receipts, payments and all the modules described above.

Why is the demo in a separate frame?

The demo runs as its own page inside an iframe, so it keeps its own UI state and interactions independent of this landing page. The landing page stays exactly where it is while you click around the demo. You can also open the demo in a new tab using the button in the demo's top bar.

What's the difference between Turnkey and Self-Hosted?

Both plans give you the exact same Shop Management System. With Turnkey ($1,200/month), we host, maintain and back it up for you — you just log in and sell. With Self-Hosted ($750 one-time), you install it on your own server and keep full control of your data and infrastructure. A video walkthrough of the self-hosting setup is coming soon.

Do I need any technical skills to use ShopFlow?

For Turnkey, no — it's fully managed. For Self-Hosted, you (or your IT person) will need basic server skills to install and maintain it. We provide a step-by-step setup video, written documentation and optional paid setup assistance.

Where can I watch the self-hosting setup video?

The video is coming soon and will be embedded in the "How to self-host ShopFlow" section above. It will walk through downloading the package, server prerequisites, installation, configuration and going live. Until then, written setup docs are available on request.

Can I switch between plans later?

Yes. You can export your data from one plan and import it into the other. Many shops start on Turnkey and move to Self-Hosted once they grow — or the other way around. We'll help you migrate at no extra cost.

Is my data safe and backed up?

On Turnkey, we run automatic daily backups and encrypt your data in transit and at rest. On Self-Hosted, you control your own backups — and we give you the scripts and docs to do it reliably.

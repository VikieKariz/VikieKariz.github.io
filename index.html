Walkthrough

How to self-host ShopFlow

A video walkthrough for the Self-Hosted plan is coming soon — below it is the full written guide you can follow right now.

Self-Hosted Setup Guide Video coming soon

Download → install → configure → go live. Full walkthrough for the Self-Hosted plan.

~12 min · Self-Hosted

Video coming soon. Until it's ready, the written guide below covers the exact same steps: prerequisites, download, database setup, configuration, running migrations, and going live. You can follow it end-to-end today.

What you'll need before you start

  • A Linux server (Ubuntu 22.04 LTS recommended)
  • 2 vCPU · 2 GB RAM minimum (4 GB recommended)
  • Node.js 18+ (or PHP 8.1+ for the PHP build)
  • PostgreSQL 14+ or MySQL 8+
  • A domain name (optional but recommended)
  • SSH access to your server
  • Basic comfort with the command line
  • The ShopFlow package (sent after purchase)
01

Connect to your server

SSH into the machine where ShopFlow will run. Update the system first.

ssh user@your-server-ip sudo apt update && sudo apt upgrade -y
02

Install dependencies

Install the runtime and database ShopFlow needs. Example for Node.js + PostgreSQL:

sudo apt install -y nodejs npm postgresql node -v # should be 18+ psql --version
03

Create the database

Create a dedicated database user and database for ShopFlow.

sudo -u postgres psql CREATE DATABASE shopflow; CREATE USER shopflow WITH PASSWORD 'strong-password'; GRANT ALL PRIVILEGES ON DATABASE shopflow TO shopflow; \q
04

Upload the ShopFlow package

Copy the package you received after purchase to your server and extract it.

scp shopflow.tar.gz user@your-server-ip:/var/www/ cd /var/www tar -xzf shopflow.tar.gz cd shopflow
05

Configure environment

Copy the sample env file and set your database URL and app secret.

cp .env.example .env nano .env # set these values: DATABASE_URL=postgres://shopflow:password@localhost:5432/shopflow APP_SECRET=a-long-random-string APP_URL=https://your-domain.com
06

Install app dependencies

Install the project's packages and build the production bundle.

npm install npm run build
07

Run database migrations

Create the tables ShopFlow needs and seed the default admin account.

npm run migrate npm run seed
08

Start the app

Start ShopFlow and confirm it's running on the expected port.

npm run start # open http://your-server-ip:3000
09

Keep it running (process manager)

Use PM2 so ShopFlow restarts automatically after crashes or reboots.

sudo npm install -g pm2 pm2 start npm --name shopflow -- run start pm2 startup pm2 save
10

Add HTTPS with a reverse proxy

Put Nginx in front and get a free TLS certificate from Let's Encrypt.

sudo apt install -y nginx certbot python3-certbot-nginx # point your domain to the server, then: sudo certbot --nginx -d your-domain.com
11

Log in and finish setup

Open your domain, log in with the seeded admin account, and walk through the first-run wizard to set your shop name, currency and tax.

# default admin (change immediately) email: admin@shopflow.local password: change-me-now
12

Set up backups (important)

Schedule a daily database dump so you can restore if something goes wrong.

pg_dump shopflow > /backups/shopflow-$(date +%F).sql # add to crontab: 0 2 * * * pg_dump shopflow > /backups/shopflow-$(date +\%F).sql

Going live checklist. Before you open the till, confirm: HTTPS is working, the admin password is changed, your database has a daily backup job, and a test sale goes through end-to-end. If any step fails, the written setup docs and support team are there to help.

FAQ

Frequently asked questions

Everything you need to know before getting started.

Is the demo on this page the real product?

Yes. The Live Demo launches a real, running instance of ShopFlow in a new tab, pre-seeded with sample data so you can explore the actual POS, inventory and reports. The sample data resets periodically — it's a sandbox, so please don't enter real customer information.

What's the difference between Turnkey and Self-Hosted?

Both plans are a one-time purchase — there's no monthly subscription. With Turnkey ($1,200 one-time), we install ShopFlow on your server and make sure it's running, then hand over full access. You own the server, the data and the license. With Self-Hosted ($750 one-time), we give you the package and you install it yourself. Either way, you own everything.

Do I need any technical skills to use ShopFlow?

For Turnkey, no — we install it for you. For Self-Hosted, you (or your IT person) will need basic server skills to install and maintain it. We provide a step-by-step written guide (see the "How to self-host ShopFlow" section above — the video walkthrough is coming soon) and optional paid setup assistance.

Where can I find the self-hosting instructions?

The "How to self-host ShopFlow" section above contains a full written guide — prerequisites, server setup, database, configuration, migrations, running the app, HTTPS, and backups. You can follow it end-to-end today. The video walkthrough is coming soon and will cover the same steps.

Can I switch between plans later?

Yes. You can export your data from one plan and import it into the other. Many shops start on Self-Hosted and move to Turnkey (or the other way around) as their needs change. We'll help you migrate at no extra cost.

Is my data safe and backed up?

ShopFlow encrypts your data in transit and at rest and gives you the tooling to run reliable backups. Because it's installed on your own server, your data never leaves your infrastructure — you control the backups. The self-hosting guide above includes a daily backup cron example.

Can I use ShopFlow on multiple branches?

Yes. ShopFlow supports multi-location inventory, per-branch reporting and branch-level staff permissions. You can transfer stock between branches and see consolidated reports across all locations.

Does ShopFlow work offline?

The POS is designed to keep ringing up sales even if your connection drops — transactions sync back once you're online. Inventory and customer records stay consistent across devices.

What payment methods are supported?

Cash, cards, mobile money (including M-Pesa) and split payments are all supported at checkout. You configure the gateways you use — no forced payment vendor.

How do I get support?

Turnkey customers get priority email and chat support during the install and after. Self-Hosted customers can add an optional support plan, or use the written docs. Either way, you'll talk to a person who knows the product. See the Support & Communication section above for full details.

How do I file a complaint?

Use the Complaints form above or reach us directly on WhatsApp (+254 791 480 995), email (support@shopflow.app), or Instagram (@cloudmikkie). Every complaint is read by a real person, acknowledged within 24 hours, and we aim to resolve issues within 5 business days.

Can I get a free consultation before buying?

Absolutely. Use the Free Consultation button above or contact us to book a 20-minute, no-obligation call. We'll walk you through the plans and help you decide what fits your shop best.

What are the other projects you've built?

Beyond ShopFlow, we build Estate Vault Pro, HomeFinder AI and Realty Connect — enterprise-grade real estate tools. You can see a preview in the More Projects section above, or contact us to ask for the full portfolio.
